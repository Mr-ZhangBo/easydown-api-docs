# Security policy

## Reporting a vulnerability

Do not report security vulnerabilities in a public issue, discussion, or pull
request. Use GitHub's private vulnerability reporting for this repository so
the report and any supporting details remain private.

Include the affected page or component, reproduction steps, expected impact,
and any suggested mitigation. Do not include real production API tokens in the
report; use a redacted value or a dedicated test credential.

## Supported version

Security fixes are applied to the latest version on the `main` branch.
