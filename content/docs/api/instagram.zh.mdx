一个 REST 请求即可处理帖子、Reel、embed 和分享链接，并保留图集顺序，方便集成展示或保存完整公开帖子。

适合增加 Instagram 视频下载能力，处理已支持的公开帖子、Reels 和分享链接。

当你既需要稳定的可下载媒体，又需要平台专属字段时，使用此接口。

## 接口地址

`POST https://api.easydown.org/api/v1/platforms/instagram/parse`

## 支持的 URL 格式

- `instagram.com/reel/{id}`
- `instagram.com/p/{id}`
- `instagram.com/stories/{user}/{id}`
- `instagram.com/share/{type}/{code}`

### 可用示例

- `https://www.instagram.com/reel/DY2PcmxiBE2/`
- `https://www.instagram.com/p/DYJIhddkzi0/`
- `https://www.instagram.com/stories/wordongreene/3940061275140997661`
- `https://www.instagram.com/share/reel/BAabcdef123/`

## 该平台响应会返回什么

混合或图集帖子可能同时返回 images[] 与 videos[]；封面和缩略图候选会与可下载的帖子媒体分开保留。

## 已发布的平台数据字段

接口会保留目标作品最终响应中的其他公开字段，并递归删除敏感字段。下表字段在当前 platformDataVersion 内保持稳定。

| 字段 | 类型 | 说明 |
|---|---|---|
| `data.media` | `object` | 统一的图片、视频、音频、标题、封面和时长。 |
| `data.platformDataVersion` | `string` | Instagram的公开数据契约版本，当前为 `1`。 |
| `data.platformData.id` | `string` | 目标作品在平台中的公开标识，请按字符串保存以避免大整数精度丢失。 |
| `data.platformData.code` | `string` | 目标作品在平台中的公开标识，请按字符串保存以避免大整数精度丢失。 |
| `data.platformData.caption` | `object` | 目标作品公开展示的标题、正文或说明文字。 |
| `data.platformData.user` | `object` | 目标作品作者的公开资料字段，不包含联系方式或鉴权信息。 |
| `data.platformData.video_versions` | `array` | 目标作品的视频播放、清晰度、编码、尺寸和媒体地址信息。 |
| `data.platformData.image_versions` | `object` | 目标作品的图片、封面或图集项目；数组顺序与平台返回顺序一致。 |
| `data.platformData.carousel_media` | `array` | 目标作品的图片、封面或图集项目；数组顺序与平台返回顺序一致。 |
| `data.platformData.taken_at` | `number` | 目标作品在平台响应中的公开字段。 |

## 下载与代理建议

建议后端携带 Instagram Referer 和浏览器 User-Agent 请求。Instagram CDN 可能检查 CORS、CORP、Cookie 或过期签名，浏览器直连并不稳定。

## 限制与行为

不支持主页、Highlights、Explore、私信、私密帖子、仅登录可见媒体和已过期 Stories。

仅支持公开内容。私密、已删除、年龄限制、地区限制、直播或其他不可用内容可能解析失败，失败不消耗额度。

只有返回可下载媒体后才扣费，每次成功解析消耗 1 个额度（credit）。鉴权、参数校验、权限、内容不可用、无媒体和上游故障均不扣费。

## 故障排查

- 提交完整公开帖子或 Reel URL，不要提交账号主页。
- 浏览器出现 CORS 或 CORP 时，通过后端代理 CDN 媒体。
- Instagram CDN URL 过期后重新解析帖子。

## 常见问题

### 失败请求会消耗额度吗？

不会。只有 API 成功返回可下载媒体后才消耗 1 个额度。

### 为什么有效的公开链接仍可能失败？

作品可能已经删除、设为私密、存在地区限制、属于直播、没有可下载媒体，或上游服务暂时不可用。
