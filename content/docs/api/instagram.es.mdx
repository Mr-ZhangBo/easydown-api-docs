description: "Usa la API de Instagram con URL públicas compatibles y recibe videos, imágenes, audio y datos completos sin campos sensibles."

Envía la URL de una publicación, un Reel o una Story pública compatible. La API devuelve por separado el video y todas las imágenes disponibles del carrusel.

Úsala para descargar videos de Instagram desde publicaciones públicas, reels y enlaces compartidos compatibles.

Usa este endpoint cuando necesites campos propios de la plataforma además de medios descargables estables.

## Endpoints

`POST https://api.easydown.org/api/v1/platforms/instagram/parse`

## Formatos de URL compatibles

- `instagram.com/reel/{id}`
- `instagram.com/p/{id}`
- `instagram.com/stories/{user}/{id}`
- `instagram.com/share/{type}/{code}`

### Ejemplos aceptados

- `https://www.instagram.com/reel/DY2PcmxiBE2/`
- `https://www.instagram.com/p/DYJIhddkzi0/`
- `https://www.instagram.com/stories/wordongreene/3940061275140997661`
- `https://www.instagram.com/share/reel/BAabcdef123/`

## Contenido de la respuesta de la plataforma

Devuelve videos e imágenes por separado y conserva todos los elementos disponibles de un carrusel público.

## Campos publicados de la plataforma

La API conserva otros campos públicos del objeto final después de eliminar de forma recursiva los datos sensibles. Los campos documentados se mantienen estables durante esta versión de platformData.

| Campo | Tipo | Descripción |
|---|---|---|
| `data.media` | `object` | Imágenes, videos, audios, título, miniatura y duración normalizados. |
| `data.platformDataVersion` | `string` | Versión pública del contrato de datos de Instagram; actualmente `1`. |
| `data.platformData.id` | `string` | Identificador público del contenido. Guárdalo como texto para evitar pérdidas de precisión con números grandes. |
| `data.platformData.code` | `string` | Identificador público del contenido. Guárdalo como texto para evitar pérdidas de precisión con números grandes. |
| `data.platformData.caption` | `object` | Título, texto o descripción que se muestra públicamente en la publicación solicitada. |
| `data.platformData.user` | `object` | Datos públicos del autor de la publicación, sin contactos ni credenciales. |
| `data.platformData.video_versions` | `array` | Datos de reproducción, calidad, códec, dimensiones y URL multimedia del video solicitado. |
| `data.platformData.image_versions` | `object` | Imágenes, portadas o elementos del carrusel; el orden coincide con la respuesta de la plataforma. |
| `data.platformData.carousel_media` | `array` | Imágenes, portadas o elementos del carrusel; el orden coincide con la respuesta de la plataforma. |
| `data.platformData.taken_at` | `number` | Campo público incluido en la respuesta de la plataforma para el contenido solicitado. |

## Descarga y uso de proxy

Descarga desde el backend con Referer de Instagram y User-Agent de navegador. Las vistas directas pueden fallar por CORS, CORP, cookies o firmas temporales.

## Límites y comportamiento

No admite perfiles, mensajes directos, Explore, cuentas privadas, Stories caducadas ni Highlights no accesibles públicamente.

Solo se admite contenido público. El contenido privado, eliminado, restringido por edad o región, en directo o no disponible puede fallar sin consumir créditos.

Solo se cobra después de devolver medios descargables: 1 crédito por análisis correcto. Los fallos de autenticación, validación, permisos, contenido, medios o servicio externo no se cobran.

## Solución de problemas

- Usa la URL completa de la publicación o del Reel, no la de un perfil.
- Pasa los archivos de la CDN por tu backend si el navegador informa de CORS o CORP.
- Vuelve a analizar la publicación cuando caduque una URL multimedia de Instagram.

## Preguntas frecuentes

### ¿Una solicitud fallida consume créditos?

No. Solo se cobra 1 crédito cuando la API devuelve medios descargables.

### ¿Por qué puede fallar una URL pública válida?

La publicación puede estar eliminada, ser privada, tener restricciones regionales, ser un directo, no contener medios o sufrir una indisponibilidad externa.
