Envía una URL de video, episodio, curso o b23.tv de Bilibili China continental. La API conserva cada parte y las pistas DASH disponibles.

Úsala para descargar videos de Bilibili de China continental desde videos, series, cursos y enlaces b23.tv.

Usa este endpoint cuando necesites campos propios de la plataforma además de medios descargables estables.

## Endpoints

`POST https://api.easydown.org/api/v1/platforms/bilibili/parse`

## Formatos de URL compatibles

- `bilibili.com/video/BV{id}`
- `bilibili.com/video/av{id}`
- `b23.tv/{code}`
- `bilibili.com/bangumi/play/{id}`
- `bilibili.com/cheese/play/{id}`

### Ejemplos aceptados

- `https://www.bilibili.com/video/BV1sW4y197cE/`
- `https://www.bilibili.com/video/av45306969/`
- `https://b23.tv/INJgdai`

> Bilibili solo admite URL de China continental. bilibili.tv y bili.im (Bstation / internacional) no son compatibles.

## Contenido de la respuesta de la plataforma

Bilibili suele entregar flujos DASH de video y audio separados; también puede devolver portadas y distintas calidades.

## Campos publicados de la plataforma

La API conserva otros campos públicos del objeto final después de eliminar de forma recursiva los datos sensibles. Los campos documentados se mantienen estables durante esta versión de platformData.

| `data.platformDataVersion` | `string` | Versión pública del contrato de datos de Bilibili (China continental); actualmente `1`. |
| `data.platformData.title` | `string` | Título, texto o descripción que se muestra públicamente en la publicación solicitada. |
| `data.platformData.pic` | `string` | URL pública de un archivo, portada o página de detalle devuelta por la plataforma. |

| `data.platformData.quality` | `number` | Duración, dimensiones, calidad u otros parámetros técnicos publicados por la plataforma. |

## Descarga y uso de proxy

Descarga video y audio desde el backend con Referer de Bilibili, User-Agent y Range. Combina las pistas DASH con FFmpeg cuando estén separadas.

## Límites y comportamiento

No admite Bilibili International/Bstation, listas para ver más tarde, favoritos, perfiles, contenido de pago ni videos bloqueados por región.

Solo se admite contenido público. El contenido privado, eliminado, restringido por edad o región, en directo o no disponible puede fallar sin consumir créditos.

Solo se cobra después de devolver medios descargables: 1 crédito por análisis correcto. Los fallos de autenticación, validación, permisos, contenido, medios o servicio externo no se cobran.

## Solución de problemas

- Conserva el bvid, cid y número de parte como texto en el cliente y en la base de datos.
- Combina la pista de video elegida con una pista de audio cuando el resultado sea DASH.
- No envíes URL de bilibili.tv ni bili.im: corresponden a Bstation y no están admitidas.

## Preguntas frecuentes

### ¿Una solicitud fallida consume créditos?

No. Solo se cobra 1 crédito cuando la API devuelve medios descargables.

### ¿Por qué puede fallar una URL pública válida?

La publicación puede estar eliminada, ser privada, tener restricciones regionales, ser un directo, no contener medios o sufrir una indisponibilidad externa.
