普通视频页、图文作品和 TikTok 分享跳转都使用同一个鉴权 REST 请求，EasyDown 会统一结果并保留不同画质和图集项目。

适合为网站、应用或自动化流程增加 TikTok 视频下载能力，无需自行维护平台解析逻辑。

当你既需要稳定的可下载媒体，又需要平台专属字段时，使用此接口。

## 接口地址

`POST https://api.easydown.org/api/v1/platforms/tiktok/parse`

## 支持的 URL 格式

- `tiktok.com/@{user}/video/{id}`
- `tiktok.com/@{user}/photo/{id}`
- `tiktok.com/t/{code}`

### 可用示例

- `https://www.tiktok.com/@jesscreatescontent/video/7647557116596718861`
- `https://www.tiktok.com/@creator/photo/7512345678901234567`
- `https://www.tiktok.com/t/ZP8pT81pD/`

## 该平台响应会返回什么

视频作品可能返回多种清晰度、封面和音频；图文作品会返回源响应中公开的全部图集图片。

## 已发布的平台数据字段

接口会保留目标作品最终响应中的其他公开字段，并递归删除敏感字段。下表字段在当前 platformDataVersion 内保持稳定。

| 字段 | 类型 | 说明 |
|---|---|---|
| `data.media` | `object` | 统一的图片、视频、音频、标题、封面和时长。 |
| `data.platformDataVersion` | `string` | TikTok的公开数据契约版本，当前为 `1`。 |
| `data.platformData.aweme_id` | `string` | 目标作品在平台中的公开标识，请按字符串保存以避免大整数精度丢失。 |
| `data.platformData.desc` | `string` | 目标作品公开展示的标题、正文或说明文字。 |
| `data.platformData.author` | `object` | 目标作品作者的公开资料字段，不包含联系方式或鉴权信息。 |
| `data.platformData.video` | `object` | 目标作品的视频播放、清晰度、编码、尺寸和媒体地址信息。 |
| `data.platformData.images` | `array` | 目标作品的图片、封面或图集项目；数组顺序与平台返回顺序一致。 |
| `data.platformData.statistics` | `object` | 平台公开展示的播放、点赞、评论、收藏或分享等互动统计。 |

## 下载与代理建议

请通过后端代理携带 TikTok Referer 和浏览器 User-Agent。部分媒体需要来自你自己浏览环境的有效访问 Cookie，也可能受服务器地区影响。

## 限制与行为

不支持用户主页、直播页、声音页、搜索结果、TikTok Lite、私密作品、已删除作品和地区不可用媒体。

仅支持公开内容。私密、已删除、年龄限制、地区限制、直播或其他不可用内容可能解析失败，失败不消耗额度。

只有返回可下载媒体后才扣费，每次成功解析消耗 1 个额度（credit）。鉴权、参数校验、权限、内容不可用、无媒体和上游故障均不扣费。

## 故障排查

- 分享短链解析完成后再缓存最终作品 URL。
- 媒体 URL 返回 403 或 404 时重新解析，TikTok 链接可能过期。
- 不要在浏览器 JavaScript 中暴露 API Token 或源站 Cookie。

## 常见问题

### 失败请求会消耗额度吗？

不会。只有 API 成功返回可下载媒体后才消耗 1 个额度。

### 为什么有效的公开链接仍可能失败？

作品可能已经删除、设为私密、存在地区限制、属于直播、没有可下载媒体，或上游服务暂时不可用。
