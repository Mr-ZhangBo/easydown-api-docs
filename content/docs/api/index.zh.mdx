## 选择合适的响应结构

| 接口 | 适用场景 |
|---|---|
| [`POST /api/v1/parse`](/zh/api/common) | 需要用一套稳定媒体结构处理所有已支持平台。 |
| `POST /api/v1/platforms/{platform}/parse` | 除了统一媒体结构，还需要目标作品经过清理的平台全量数据。 |

## API 计费与额度

只有返回可下载媒体后才扣费，每次成功解析消耗 1 个额度（credit）。鉴权、参数校验、权限、内容不可用、无媒体和上游故障均不扣费。
