Envía una URL pública de foto o video de Kuaishou/Kwai, o un texto compartido que contenga un enlace compatible. La API selecciona la publicación solicitada.

Úsala para añadir descarga de videos de Kuaishou o Kwai desde publicaciones públicas y enlaces cortos compatibles.

Usa este endpoint cuando necesites campos propios de la plataforma además de medios descargables estables.

## Endpoints

`POST https://api.easydown.org/api/v1/platforms/kuaishou/parse`

## Formatos de URL compatibles

- `kuaishou.com/short-video/{id}`
- `v.kuaishou.com/{code}`
- `kwai.com/@{user}/video/{id}`

### Ejemplos aceptados

- `https://v.kuaishou.com/JuuRuozy`
- `https://www.kuaishou.com/short-video/3x2cvn2u7fq8k8s`
- `https://www.kwai.com/@volana390/video/5207718655495282041`

## Contenido de la respuesta de la plataforma

Las publicaciones individuales accesibles devuelven el archivo de video y la información disponible de portada o calidad.

## Campos publicados de la plataforma

La API conserva otros campos públicos del objeto final después de eliminar de forma recursiva los datos sensibles. Los campos documentados se mantienen estables durante esta versión de platformData.

| Campo | Tipo | Descripción |
|---|---|---|
| `data.media` | `object` | Imágenes, videos, audios, título, miniatura y duración normalizados. |
| `data.platformDataVersion` | `string` | Versión pública del contrato de datos de Kuaishou / Kwai; actualmente `1`. |
| `data.platformData.photoId` | `string` | Identificador público del contenido. Guárdalo como texto para evitar pérdidas de precisión con números grandes. |
| `data.platformData.caption` | `string` | Título, texto o descripción que se muestra públicamente en la publicación solicitada. |
| `data.platformData.author` | `object` | Datos públicos del autor de la publicación, sin contactos ni credenciales. |
| `data.platformData.mainMvUrls` | `array` | Datos de reproducción, calidad, códec, dimensiones y URL multimedia del video solicitado. |
| `data.platformData.manifest` | `object` | Datos de reproducción, calidad, códec, dimensiones y URL multimedia del video solicitado. |
| `data.platformData.coverUrls` | `array` | Imágenes, portadas o elementos del carrusel; el orden coincide con la respuesta de la plataforma. |
| `data.platformData.duration` | `number` | Duración, dimensiones, calidad u otros parámetros técnicos publicados por la plataforma. |
| `data.platformData.width` | `number` | Duración, dimensiones, calidad u otros parámetros técnicos publicados por la plataforma. |
| `data.platformData.height` | `number` | Duración, dimensiones, calidad u otros parámetros técnicos publicados por la plataforma. |

## Descarga y uso de proxy

Descarga desde el backend con Referer de Kuaishou, User-Agent y Range. Conserva la consulta de las URL firmadas y vuelve a analizar después de su vencimiento.

## Límites y comportamiento

No admite directos, perfiles, búsquedas, colecciones, videos privados o eliminados ni tokens compartidos caducados.

Solo se admite contenido público. El contenido privado, eliminado, restringido por edad o región, en directo o no disponible puede fallar sin consumir créditos.

Solo se cobra después de devolver medios descargables: 1 crédito por análisis correcto. Los fallos de autenticación, validación, permisos, contenido, medios o servicio externo no se cobran.

## Solución de problemas

- Resuelve el enlace corto antes de guardar photoId o la URL final en caché.
- Conserva todos los parámetros de la URL del video al transmitirla desde el backend.
- Los enlaces `/f/{id}` de reproducción de directos no están admitidos y no deben enviarse a la API.

## Preguntas frecuentes

### ¿Una solicitud fallida consume créditos?

No. Solo se cobra 1 crédito cuando la API devuelve medios descargables.

### ¿Por qué puede fallar una URL pública válida?

La publicación puede estar eliminada, ser privada, tener restricciones regionales, ser un directo, no contener medios o sufrir una indisponibilidad externa.
