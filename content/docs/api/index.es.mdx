## Elige el tipo de respuesta

| API | Úsala cuando |
|---|---|
| [`POST /api/v1/parse`](/es/api/common) | Necesitas un modelo multimedia estable para todas las plataformas compatibles. |
| `POST /api/v1/platforms/{platform}/parse` | Necesitas medios normalizados y el objeto completo de la plataforma, sin campos sensibles. |

## Créditos y facturación de la API

Solo se cobra después de devolver medios descargables: 1 crédito por análisis correcto. Los fallos de autenticación, validación, permisos, contenido, medios o servicio externo no se cobran.
