## APIレスポンスの選び方

| API | 適した用途 |
|---|---|
| [`POST /api/v1/parse`](/ja/api/common) | すべての対応プラットフォームを1つの安定したメディア形式で扱う場合。 |
| `POST /api/v1/platforms/{platform}/parse` | 正規化メディアに加えて、機密項目を除去した完全なプラットフォームデータが必要な場合。 |

## API料金とCredits

ダウンロード可能なメディアを返した場合のみ1クレジットを消費します。認証、入力検証、権限、コンテンツ利用不可、メディアなし、外部サービス障害は課金されません。
