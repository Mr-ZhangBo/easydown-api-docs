---

Envía una URL pública de YouTube, Shorts o youtu.be a la API. La respuesta conserva las variantes de video y audio para que el backend elija el formato adecuado.

Úsala para añadir descarga de videos de YouTube y conservar un único modelo multimedia en toda la aplicación.

Usa este endpoint cuando necesites campos propios de la plataforma además de medios descargables estables.

## Endpoints

`POST https://api.easydown.org/api/v1/platforms/youtube/parse`

## Formatos de URL compatibles

- `youtube.com/watch?v={id}`
- `youtube.com/shorts/{id}`
- `youtube.com/live/{id}`
- `youtu.be/{id}`

### Ejemplos aceptados

- `https://www.youtube.com/watch?v=BiBY6TeIvJ4`
- `https://youtu.be/MEoxtFRfPoc`
- `https://www.youtube.com/shorts/xzOtM0x3_LU`

## Contenido de la respuesta de la plataforma

Puede mostrar distintas resoluciones y pistas de audio. Algunos formatos DASH de alta calidad requieren combinar video y audio después de descargarlos.

## Campos publicados de la plataforma

La API conserva otros campos públicos del objeto final después de eliminar de forma recursiva los datos sensibles. Los campos documentados se mantienen estables durante esta versión de platformData.

| Campo | Tipo | Descripción |
|---|---|---|
| `data.media` | `object` | Imágenes, videos, audios, título, miniatura y duración normalizados. |
| `data.platformDataVersion` | `string` | Versión pública del contrato de datos de YouTube; actualmente `1`. |
| `data.platformData.videoDetails` | `object` | Estado de reproducción, formato u otros metadatos públicos del contenido. |
| `data.platformData.streamingData` | `object` | Datos de reproducción, calidad, códec, dimensiones y URL multimedia del video solicitado. |
| `data.platformData.playabilityStatus` | `object` | Estado de reproducción, formato u otros metadatos públicos del contenido. |
| `data.platformData.microformat` | `object` | Estado de reproducción, formato u otros metadatos públicos del contenido. |
| `data.platformData.captions` | `object` | Estado de reproducción, formato u otros metadatos públicos del contenido. |

## Descarga y uso de proxy

Descarga desde el backend con User-Agent de navegador, Referer y Origin de YouTube, y reenvía Range. Algunos flujos dependen de la región o IP que realizó el análisis.

## Límites y comportamiento

No admite listas, canales, publicaciones de comunidad, videos privados, contenido para miembros, DRM ni bloqueos regionales.

Solo se admite contenido público. El contenido privado, eliminado, restringido por edad o región, en directo o no disponible puede fallar sin consumir créditos.

Solo se cobra después de devolver medios descargables: 1 crédito por análisis correcto. Los fallos de autenticación, validación, permisos, contenido, medios o servicio externo no se cobran.

## Solución de problemas

- Combina el video y el audio por separado cuando la calidad elegida no incluya sonido.
- Vuelve a analizar la URL original si un flujo firmado caduca o responde con 403.
- Usa una región de backend que tenga acceso cuando el video público esté limitado geográficamente.

## Preguntas frecuentes

### ¿Una solicitud fallida consume créditos?

No. Solo se cobra 1 crédito cuando la API devuelve medios descargables.

### ¿Por qué puede fallar una URL pública válida?

La publicación puede estar eliminada, ser privada, tener restricciones regionales, ser un directo, no contener medios o sufrir una indisponibilidad externa.
